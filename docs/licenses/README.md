# Dependency license inventory

Snapshot: 19 September 2026, Python 3.9.6, Darwin arm64.

This directory preserves license and notice files for all 38 packages in the
installed default runtime dependency graph of `requirements.txt`. It contains
license texts, not copies of the Python packages. Streamlit license/notice files
were retrieved from its official `1.50.0` source tag because its installed wheel
does not include standalone license files. All copied texts are unmodified.

[inventory.json](inventory.json) records versions, source locations, dependency
metadata and SHA-256 hashes for each retained file. Long license texts and
bundled-component notices remain in full; the table only summarises them.

This is an evidence snapshot, not a lockfile or a certification of all source
files. `requirements.txt` allows later versions; another Python version or OS
can resolve different dependencies and bundled native libraries. Refresh the
inventory when making a release from a different environment. See the
[review and release scope](../LICENSING.md).
